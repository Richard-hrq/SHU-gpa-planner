# 上大绩点规划助手 shu-gpa-planner
上海大学教务系统专用油猴(Tampermonkey)脚本，自动读取已修绩点、课表，按课程难度浮动计算每门课建议目标绩点（上大11档离散绩点标准）

## ✨ 核心功能
1. 多渠道自动抓取当前绩点
   - 成绩查询接口自动获取
   - 学业情况页面DOM解析
   - 成绩总表HTML/PDF解析
   - 支持手动输入绩点、学分兜底
2. 自动同步下学期课表/选课列表
3. 内置课程难度数据库（1简单~5很难），支持自定义单门课程难度
4. 难度浮动算法：难课自动拉高建议分数，水课降低压力
5. 贪心微调11级离散绩点，精准达成目标总绩点
6. 可视化悬浮面板，拖拽窗口、一键计算
7. 本地持久化保存所有数据，刷新页面不丢失

## 📊 上海大学绩点标准（11档离散）
| 分数区间 | 绩点 | 等级 |

## 📦 安装使用
1. 浏览器安装油猴插件 Tampermonkey
   - Chrome/Edge：应用商店搜索 Tampermonkey
   - Firefox：附加组件商店
2. 进入本仓库，打开 `shu-gpa-planner.user.js` 文件
3. 点击右上角 **Raw**，油猴会自动弹出安装窗口，点击安装
4. 登录上海大学教务系统：
   - 成绩页面：自动抓取已修绩点
   - 课表页面：自动加载下学期课程
5. 点击页面右下角 📊 悬浮按钮打开计算面板，输入目标绩点一键计算

## ⚙️ 功能说明
- 目标绩点：填写你想要的毕业总绩点
- 难度浮动系数：数值越大，难易课程的目标分差距越大（0=所有课程均分）
- 点击课程难度标签可手动修改单门课难度
- 支持手动添加自定义选课、手动录入绩点学分
